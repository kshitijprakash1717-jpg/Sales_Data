# Amazon Sales Analysis

This project analyzes Amazon sales data using SQL, Power BI, and Python to uncover trends, customer behavior, profitability insights, and forecasting opportunities.

## Project Overview

The goal of this project is to transform raw sales data into meaningful business insights. It combines:

- SQL for data extraction and transformation
- Power BI for interactive dashboarding and visual analysis
- Python for exploratory analysis and forecasting

## Key Objectives

- Analyze total sales and profit performance
- Identify top-selling products and categories
- Track monthly and yearly sales trends
- Study customer buying patterns and segmentation
- Measure discount impact on profitability
- Forecast future sales using data-driven techniques

## Tools and Technologies

- SQL
- Power BI
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Structure

- `README.md` – project overview and usage instructions
- `Amazon_sales_analysis.sql` – SQL queries for analysis
- `Amazon_sales_powerbi_dashboard.pdf` – Power BI dashboard export
- `Amazon_sales_py.ipynb` – Python notebook for analysis and forecasting

## Business Insights Covered

- Sales and profit calculations
- Monthly and yearly sales trends
- Best-selling categories and products
- Regional sales and shipping cost analysis
- Customer review and payment preference analysis
- Product profitability influenced by discounts
- Sales forecasting using moving averages and predictive models

## Recommended Workflow

1. Load the dataset in your SQL environment.
2. Run the queries in `Amazon_sales_analysis.sql`.
3. Open the Power BI dashboard for visual insights.
4. Execute the Python notebook for deeper statistical and forecasting analysis.

## Getting Started

### Prerequisites
